Q-1.투자자산 대비 Ty수익율은 어느 값이 맞습니까

현재 상태

화면은 정의서 ⑤(유량 기준)로 맞춰 10.72%를 쓴다. 같은 실적을 분모만 바꿔 읽으면 12.59%(PSC를 평균 순현금으로)·12.13%(분모를 기준일 잔액으로)가 되어 갈린다. 정의서 안에서 PSC 처리가 정해지지 않은 것이 남은 문제다.

정의서 안에서도 PSC 처리가 갈린다. 배치 항목은 평균순현금을 산출한다고 적었는데 PSC는 EC들의 합으로 정의돼 있다. 합으로 보면 737,100,000(105,300,000 × 7일), 평균으로 보면 105,300,000이고 결과가 1%p 넘게 벌어진다.

왜 묻는지
제안서에 실리는 수익율 지표라, 같은 실적이 10.72%로도 12.59%로도 읽힌다. 1.17배 차이다.
원문 근거
투자자산 대비 ty수익율 (이미지의 ⑤) = (이미지의 ④ x PSA) / (PSA + PSC) PSC = 위 선택한 기간의 EC들의 합 … w금융일수(SDD-1), ty수익율, 평균순현금 산출해 DB 업데이트
선택지

④ = 12.97%, PSA = 3,511,071,647 고정

  • A안PSC를 기간 EC 합 737,100,000으로. ⑤ = 10.7157% → 10.72% (정의서 문자 그대로 · 현행 화면)
  • B안PSC를 평균 순현금 105,300,000으로. ⑤ = 12.5878% → 12.59%
  • C안분모를 기준일 잔액으로. ④ × 투자실행액 ÷ 투자자산 = 12.1269% → 12.13%

Q-2.가맹점별 투자자산 표의 비중 열을 어떻게 합니까

현재 상태

한 화면에 비중이라는 같은 이름의 열이 두 개 있고 분모가 다르다. 현황표 2행은 분모가 투자자산 1,628,400,000(93.5% / 6.5%), 가맹점별 16행은 분모가 투자실행액 1,523,100,000(합 100.0%). 분모가 다르다는 단서는 화면에도 엑셀 6종에도 없다. 정의서의 비중은 투자실행액과 순현금 2행만 규정하고 가맹점별 축은 언급이 없다.

아울러 16행을 소수 1자리로 반올림한 합이 100.0%에서 어긋나면 잔차를 최대 금액 행(김성호떡볶이 본점, 268,181,516)에 몰아 맞춘다. 지금 데이터에서는 잔차가 0이라 흡수가 없다. 이 표는 투자자산 증명서 PDF에도 그대로 실린다.

왜 묻는지
증명서 PDF 16건 · 엑셀 1종 · Figma 2프레임이 이 열 하나에 함께 걸려 있어, 정해지기 전에는 재발행을 못 한다.
원문 근거
투자 실행액의 비중 = 투자실행액 / (투자실행액 + 순현금) 순현금의 비중 = 순현금 / (투자실행액 + 순현금)
선택지
  • A안존치하되 열 이름을 분리(예: 투자실행액 대비 구성비). 16행 합계 100.0% 유지, 숫자 변동 없음
  • B안분모를 투자자산으로 통일. 16행 합계 100.0% → 93.5%, 최대 행 17.6% → 16.5%
  • C안폐기. 증명서 PDF와 엑셀에서 열 삭제

Q-3.조달이자형(연 12%) 산식 카드를 계속 둡니까

현재 상태
화면 11개가 산식 카드 2종을 나란히 두고 있다. 수수료 배분형 0.11%와 조달이자형 투자실행금 × 연 12% × 사용일수 ÷ 365. 정의서는 채권매입수수료 기반 1모델만 제시하고 연 12%를 언급하지 않는다.
왜 묻는지
두 모델이 동시에 걸리는 것인지 둘 중 하나를 고르는 것인지에 따라 투자수익 열의 산출 근거가 달라진다.
원문 근거
정의서에 연 12%를 언급한 문장이 없다. 병기는 이전 결정 D-1에서만 나온다.
선택지
  • A안2모델 병기 유지
  • B안정의서에 맞춰 채권매입수수료 1모델로 접고 조달이자형 카드 삭제(화면 11개)

Q-4.화면의 0.11%를 단서 없이 인쇄해도 됩니까

현재 상태
정의서는 0.11% 예정으로 적었다. 화면 제목은 수익 산정 기준이고 요율에 붙는 각주는 0건이다. 화면은 0.11%를 단서 없이 인쇄한다. 정의서의 할인율은 유동화투자자 단위 단일값이다.
왜 묻는지
제안서 첨부용 화면이라 단서 없는 0.11%가 대외에 확정 요율로 읽힌다.
원문 근거
유동화투자자의 할인율 = 0.11% 예정
선택지
  • A안현행 유지. 화면은 0.11%만 인쇄한다
  • B안예정 단계임을 제안서 본문에 적고 화면은 그대로 둔다

투자자 어드민 계산식 — 확인 요청

주신 용어 정의서를 투자자 어드민 화면과 엑셀에 적용하는 중에, 정의서만으로는 값이 하나로 정해지지 않는 곳이 4군데 남았습니다. 아래 순서대로 회신 주시면 화면 숫자를 확정하겠습니다.

앞서 여쭈려던 3건 — 정의서가 가리키는 번호 마커, 채권매입수수료의 기준금액·요율, '미지급금'·'과지급금'의 정의 — 은 사내에서 자료와 운영 어드민 화면을 대조해 닫았습니다. 번호 마커는 스토리보드 캡처 2장의 마커와 1:1로 맞췄고, 채권매입수수료는 계약별로 정해지는 요율이라 어드민 요율 설정에서 읽어 옵니다. '미지급금'·'과지급금'은 어드민에 이미 있는 개념(선정산 지급 대상인데 못 준 금액 / 더 나간 금액)과 같은 것으로 확인했습니다. 회신 대상이 아닙니다.

숫자는 화면 기준일 2026-08-27, 조회 기간 2026-08-21 ~ 08-27(일주일) 기준입니다.

[회신이 필요한 4건]
Q-1. 투자자산 대비 Ty수익율은 어느 값이 맞습니까

  현재 상태 : 화면은 정의서 ⑤(유량 기준)로 맞춰 10.72%를 씁니다. 같은 실적을 분모만 바꿔 읽으면 12.59%(PSC를 평균 순현금으로)·12.13%(분모를 기준일 잔액으로)가 되어 갈립니다. 정의서 안에서 PSC 처리가 정해지지 않은 것이 남은 문제입니다.
             정의서 안에서도 PSC 처리가 갈립니다. 배치 항목은 '평균순현금'을 산출한다고 적었는데 PSC는 'EC들의 합'으로 정의돼 있습니다. 합으로 보면 737,100,000(105,300,000 × 7일), 평균으로 보면 105,300,000이고 결과가 1%p 넘게 벌어집니다.
  왜 묻는지 : 제안서에 실리는 수익율 지표라, 같은 실적이 10.72%로도 12.59%로도 읽힙니다. 1.17배 차이입니다.
  원문 근거 : "투자자산 대비 ty수익율 (이미지의 ⑤) = (이미지의 ④ x PSA) / (PSA + PSC)"
             "PSC = 위 선택한 기간의 EC들의 합"
             "… w금융일수(SDD-1), ty수익율, 평균순현금 산출해 DB 업데이트"
  선택지    : ④ = 12.97%, PSA = 3,511,071,647 고정
             A안 — PSC를 기간 EC 합 737,100,000으로. ⑤ = 10.7157% → 10.72% (정의서 문자 그대로 · 현행 화면)
             B안 — PSC를 평균 순현금 105,300,000으로. ⑤ = 12.5878% → 12.59%
             C안 — 분모를 기준일 잔액으로. ④ × 투자실행액 ÷ 투자자산 = 12.1269% → 12.13%

[나머지 4건]
Q-2. 가맹점별 투자자산 표의 '비중' 열을 어떻게 합니까

  현재 상태 : 한 화면에 '비중'이라는 같은 이름의 열이 두 개 있고 분모가 다릅니다. 현황표 2행은 분모가 투자자산 1,628,400,000(93.5% / 6.5%), 가맹점별 16행은 분모가 투자실행액 1,523,100,000(합 100.0%)입니다. 분모가 다르다는 단서는 화면에도 엑셀 6종에도 없습니다. 정의서의 비중은 투자실행액과 순현금 2행만 규정하고 가맹점별 축은 언급이 없습니다.
             아울러 16행을 소수 1자리로 반올림한 합이 100.0%에서 어긋나면 잔차를 최대 금액 행(김성호떡볶이 본점, 268,181,516)에 몰아 맞춥니다. 지금 데이터에서는 잔차가 0이라 흡수가 없습니다. 이 표는 투자자산 증명서 PDF에도 그대로 실립니다.
  왜 묻는지 : 증명서 PDF 16건 · 엑셀 1종 · Figma 2프레임이 이 열 하나에 함께 걸려 있어, 정해지기 전에는 재발행을 못 합니다.
  원문 근거 : "투자 실행액의 비중 = 투자실행액 / (투자실행액 + 순현금)"
             "순현금의 비중 = 순현금 / (투자실행액 + 순현금)"
  선택지    : A안 — 존치하되 열 이름을 분리(예: '투자실행액 대비 구성비'). 16행 합계 100.0% 유지, 숫자 변동 없음
             B안 — 분모를 투자자산으로 통일. 16행 합계 100.0% → 93.5%, 최대 행 17.6% → 16.5%
             C안 — 폐기. 증명서 PDF와 엑셀에서 열 삭제
Q-3. 조달이자형(연 12%) 산식 카드를 계속 둡니까

  현재 상태 : 화면 11개가 산식 카드 2종을 나란히 두고 있습니다. '수수료 배분형 0.11%'와 '조달이자형 투자실행금 × 연 12% × 사용일수 ÷ 365'입니다. 정의서는 채권매입수수료 기반 1모델만 제시하고 연 12%를 언급하지 않습니다.
  왜 묻는지 : 두 모델이 동시에 걸리는 것인지 둘 중 하나를 고르는 것인지에 따라 투자수익 열의 산출 근거가 달라집니다.
  원문 근거 : 정의서에 연 12%를 언급한 문장이 없습니다. 병기는 이전 결정 D-1에서만 나옵니다.
  선택지    : A안 — 2모델 병기 유지
             B안 — 정의서에 맞춰 채권매입수수료 1모델로 접고 조달이자형 카드 삭제(화면 11개)
Q-4. 화면의 0.11%를 단서 없이 인쇄해도 됩니까

  현재 상태 : 정의서는 '0.11% 예정'으로 적었습니다. 화면 제목은 '수익 산정 기준'이고 요율에 붙는 각주는 0건입니다. 화면은 0.11%를 단서 없이 인쇄합니다. 정의서의 할인율은 유동화투자자 단위 단일값입니다.
  왜 묻는지 : 제안서 첨부용 화면이라 단서 없는 0.11%가 대외에 확정 요율로 읽힙니다.
  원문 근거 : "유동화투자자의 할인율 = 0.11% 예정"
  선택지    : A안 — 현행 유지. 화면은 0.11%만 인쇄합니다
             B안 — '예정' 단계임을 제안서 본문에 적고 화면은 그대로 둡니다
